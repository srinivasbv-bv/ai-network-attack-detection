AI Architecture & Ensemble Pipeline Explanation

Ensemble Fusion & MITRE Mapping

1. Flow-Based Deep Learning Model (Deep MLP Neural Network)

Role: Receives 12 flow-level statistical features (packet rate, flow duration, SYN/RST/ACK counts, failed auths, destination port).

Target Attack Classes: DoS, DDoS, Port Scanning, Brute-Force, Normal.

Input/Output: Input vector (1x12 normalized) ➔ 128 -> 64 -> 32 Dense ReLU layers ➔ Softmax class probabilities.

2. Protocol-Level Random Forest Anomaly Detector

Role: Receives 5 ARP protocol metrics (request rate, reply rate, reply/req ratio, MAC change rate, conflict count).

Target Attack Classes: ARP Spoofing / Man-in-the-Middle (MITM) Anomalies.

Input/Output: Input vector (1x5 normalized) ➔ 100 Decision Trees (max_depth=10) ➔ Anomaly probability score.

3. Ensemble Fusion & Decision Logic

Decision Rule: If ARP protocol anomaly score > 0.60, prioritize ARP Spoofing detection. Otherwise, use Deep Learning flow prediction.

Score Output: Weighted Threat Index (0 - 100) + Severity Tag + MITRE ATT&CK technique mapping.

System Drawbacks & Architectural Limitations

Examiner Project Review Notes

1. Dataset Dependency & Distribution Shift

Model performance relies on historical benchmark distribution. Shifts in real-world network protocols or novel network payloads may degrade classification accuracy over time.

2. False Positive & False Negative Trade-Offs

Excessive False Positives cause alert fatigue for security analysts. Conversely, False Negatives represent missed intrusions, making FNR (False Negative Rate) monitoring critical.

3. Explainability Limitations

Deep Learning model outputs are probabilistic. While feature reasoning provides rule-based explanations, black-box neural networks lack full mathematical interpretability.

4. Simulation vs. Hardware Capture

This implementation uses simulated flow streams for demonstration purposes. Deployment on physical networks requires dedicated packet capture taps (e.g., Libpcap / Scapy).

5. Automated Mitigation Disclaimer

Automated inline IP blocking can cause unintended denial of service if triggered by false positives. Response actions are provided as Recommended Analyst Guidance.

6. Zero-Day & Unseen Attack Scope

Supervised neural networks excel at known attack structures. Novel zero-day exploits absent from training datasets rely on the Random Forest anomaly threshold.
